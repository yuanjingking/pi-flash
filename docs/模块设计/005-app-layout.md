### 底部终端面板（2026-11 用户定案）

终端**不再占内容区 topbar 标签**：打开终端 = 展开内容区下沿的这块面板，并在
面板内新开一个终端标签。

- 版式：上沿 12px 命中带（§5.12 统一分隔线，拖动改高度、双击复位，高度落
  `UiState::term_h`）+ 38px 标签条（`tokens::panel_ctrl::BAR_H`，tab 高 = 条高
  −4；右侧「新建终端 / 收起」两图标钮）+ 终端体（`TerminalElement`，网格随元素
  bounds 自适应）。
- 多标签：每条终端一个标签（标题 = 起始终端 cwd 的目录名），点击切换、`×`
  或中键关闭；标签溢出横向滚动，激活标签自动滚进视口。
- 收起 = 只隐藏，PTY 保活；`Ctrl+`` 或会话功能栏终端钮切换。终端列表与
  激活位落 `TabsState::terms/term_active/term_open`（重启按 cwd 重生 PTY）。
- 实现在 `crates/app/src/terminal/panel.rs`（挂载点 `shell/render.rs` 内容区列）。
